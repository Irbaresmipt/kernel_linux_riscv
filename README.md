# kernel_linux_riscv

Ошибки с которыми можно столкнутся при поднятии скриптов:

Ubuntu 26.04

При компиляции buildroot:
1) На новых версиях gcс компиляция может упасть при раскрытии макроса strstr
Решение: в include/string.h убрать данный макрос #undef strstr

2) По умолчанию в компиляции стоит Werror, поэтому она будет переодически падать, поскольку в коде есть warningи
Решение: Флаги компиляции: CFLAGS="-D_FORTIFY_SOURCE=0, -Wno-error=discarded-qualifiers" + в скриптах подавить варнинги

3) В buildroot нет хеша для linux-6.19.5.tar.xz, есть только для предыдущей версии
Решение: Вручную выкачать и посчитать хеш и записать внутрь buildroot
